# BusinessPro Dashboard 📊

A modern and responsive **Business Analytics Dashboard** built with React.js.

BusinessPro provides a clean dashboard interface for monitoring revenue, sales, customers, products, transactions and business performance.

---

## 🚀 Features

- 📊 Business Analytics Dashboard
- 💰 Revenue & Sales Analytics
- 👥 Customer Management
- 📦 Product & Inventory Management
- 🧾 Transactions
- 📈 Reports
- ⚙️ Settings
- 🔍 Global Search
- 📱 Responsive Design
- 🌙 Dark Mode Support
- 🎨 Modern Professional UI

---

## 🛠️ Tech Stack

- **React.js**
- **React Router DOM**
- **Recharts**
- **Lucide React**
- **JavaScript**
- **CSS3**
- **Create React App**
